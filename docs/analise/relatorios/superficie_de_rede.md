```xml
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
    <debug-overrides>
        <trust-anchors>
            <certificates src="user" />
        </trust-anchors>
    </debug-overrides>
    <base-config cleartextTrafficPermitted="true" />
    <domain-config cleartextTrafficPermitted="true">
        <domain includeSubdomains="true">127.0.0.1</domain>
        <domain includeSubdomains="true">cdn-project-feed.kinemasters.com</domain>
    </domain-config>
</network-security-config>
```

**Fato observado:** `cleartextTrafficPermitted="true"` na configuração base, com domínios explicitamente autorizados para HTTP claro. `debug-overrides` confia em certificados instalados pelo usuário — o que facilita a observação de tráfego em build de depuração, mas **não** implica interceptação possível em build de release.
